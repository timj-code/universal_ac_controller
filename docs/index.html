Tips:

  1. For the very first installation, hold the button on board while plugging it into the USB.
  2. Use a browser with Web Serial support (Chrome or Edge recommended).
  3. Click Connect & Install, select the serial port and follow the installer prompts.
  4. After downloading, if the bule LED doesn't light up, unplug the device and plug in again WITHOUT pressing the button to get the firmware run.

Note: No OTA is available at the moment, If you need to upgrade the firmware, you have to use this web installer again.
